# FluentPath — image prompts

Save each image into the `assets/` folder with **exactly** the file name shown. Nothing breaks if a file is missing: the app falls back to its built-in graphics.
Generate the **mascot first**, then attach it as a reference image when making the others so the style stays consistent.

**Shared style line (add to every prompt):**
`soft 3D render, glossy frosted-glass look, rounded friendly shapes, gradient from violet #7c5cff to cyan #19d3da, gentle glow, clean modern app-illustration style, no text unless stated, no watermark`

---

## 1. logo.png — 1024×1024, transparent background
Minimal modern app logo icon for an English-learning app called FluentPath. A rounded-square badge with a smooth gradient from violet #7c5cff to cyan #19d3da. Inside it a bold white letter "F" drawn as one flowing path/ribbon that ends in a small round dot like a speech-bubble. Flat vector feel with a soft inner highlight. Centered, generous padding, no text, transparent background.

## 2. favicon.png — 256×256, transparent background
Ultra-simple version of the FluentPath logo: rounded-square, violet-to-cyan gradient, a single bold white letter "F", readable at 16 px, no fine detail, transparent background.

## 3. mascot.png — 1024×1024, transparent background
Friendly owl mascot named Lexi for an English-learning app. Round body in violet #7c5cff fading to cyan #19d3da, big shiny cartoon eyes, tiny graduation cap, one wing raised waving hello, warm smile. Soft 3D render, glossy, full body, centered, transparent background.

## 4. hero.jpg — 1600×640 (wide banner for the welcome card)
Wide illustration for a language-learning welcome screen: a cheerful learner sitting with a laptop, glowing speech bubbles floating around them containing the words "Hello", "Fluent", "IELTS" and a small staircase of steps labelled A1, A2, B1, B2, C1 rising to the right. Deep navy background #080918 with a soft violet-and-cyan aurora glow. Flat-3D style, leave the left third calmer and emptier. No other text.
